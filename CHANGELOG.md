# Changelog

All notable changes to Shityo are recorded here. Dates use the release date.

## [Unreleased]

### Added

- Bootstrap and local launcher scripts for a fresh checkout.
- Wrapper for the pinned house-style checker in local development.
- Public repository infrastructure, locked dependencies and golden-repo checks.

## [0.1.0] - 2026-11-04

### Added

- Four deterministic garment blocks with contour validation.
- 2D construction edits, seam comparison and approximate 3D visualization.
- Full-scale PDF layouts, calibration sheets and assembly maps.
- Browser-local named designs, undo/redo and validated JSON transfer.
- An attributed catalog of 85 patterns from three external publishers.
