# Собственные модели

Собственная модель строится на одной из четырёх поддерживаемых основ:
футболка, рубашка, брюки, юбка. Это параметрическое моделирование, а не
произвольное рисование контуров с нуля. Модели внешних авторов не подменяются
этими основами и не импортируются в редактор автоматически.

На странице каталога раздел «Мои модели» позволяет выбрать основу и открыть
новую модель. В редакторе доступны мерки клиента, параметры фасона, история
последних 50 правок с отменой/повтором. Для футболки и рубашки доступны числовые
координаты плечевой точки и глубины проймы; те же точки можно перетаскивать на
холсте. Сброс правок возвращает точки к расчётному положению.

Панель «Моя модель» сохраняет название, мерки, параметры и правки точек.
Сохранение проверяет геометрию на сервере и не принимает устаревший снимок,
если пользователь изменил состояние во время проверки. Можно сохранить копию.
Модели хранятся в localStorage, ключ shityo.design-projects.v1. На другом браузере
их не будет. Для резервной копии и переноса есть экспорт/импорт проекта JSON.
PDF печатается существующей панелью печати, с актуальными параметрами и правками.

Импорт ограничен 100 KB и версией 1, проверяет модель, все обязательные мерки (недостающая длина от талии до бёдер в старых проектах футболок и рубашек заполняется значением по умолчанию 20 см),
диапазоны, типы, допустимые параметры фасона и правки точек. Новый идентификатор
при импорте предотвращает случайную перезапись проекта. Проект с ошибкой данных
не заменяет существующие проекты. Невалидная геометрия показывается средствами
редактора; печать и сохранение при ошибках построения недоступны.

Проект JSON не является файлом лекала SVG/DXF и не содержит внешние фотографии.
Правки не применяются к оригинальным конструкциям FreeSewing/Mood/Tiana.


При переключении основы или открытии другого проекта редактор получает
отдельное состояние: сохранённая футболка не перезаписывается новой рубашкой.
При сбое расчётного сервера скачивание корректного JSON остаётся доступным.
Если панель проверки скрыта, ошибки показываются отдельной кнопкой над полем.

Итоговая проверка: 195 Python-тестов, 36 браузерных сценариев прошли.
Svelte: 0 ошибок и предупреждений; 323 ключа RU/EN; production build успешен.
Impeccable detect не выдал замечаний. Изображения и компоновка проверены визуально.
