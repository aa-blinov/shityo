# Библиотека реальных лекал

Источник: https://freesewing.eu/designs/ (проверен 2026-11-04).

В библиотеке 73 именованные модели официального каталога FreeSewing.
Служебный Design Part Library исключён. Каталог содержит 146 ссылок на примеры
работ, взятых со страниц моделей, и 212 уникальных изображений моделей/примеров.
Все страницы моделей загружены успешно; для всех изображений HEAD-проверка
вернула HTTP 200. Отчёт: work/library-image-verification.json.

## Что подключено

Каталог с поиском по названию, русскому описанию и автору; 10 разделов;
страница каждой модели с автором, сложностью, оригинальным названием,
изображением, примерами, ссылками на инструкции и редактор FreeSewing.
Русские названия описывают тип изделия; оригинальные имена сохранены.

Модели FreeSewing помечены как external: генерация, скачивание и печать
выполняются в оригинальном редакторе FreeSewing. Они не подменяются нашими
четырьмя основами. Прямой импорт их конструкций в наш редактор не реализован.
Четыре собственные основы доступны отдельно в разделе «Наш конструктор».
40 предварительно подготовленных параметрических вариаций удалены из каталога
после уточнения требования пользователем. Они не выдаются за реальные дизайны.

## Происхождение данных

scripts/import_freesewing_library.py получает официальный список и каждую
страницу модели; URL редактора и примеров извлекаются из реальных ссылок,
а не создаются по предполагаемому шаблону. Снимки HTML: work/library-sources/.
Каталог: backend/app/drafts/library.json; синхронная копия для интерфейса:
frontend/src/lib/fixtures/library.json. API: GET /api/library.

Авторы считываются из страниц моделей. Сложность, теги и версия кода дополнены
официальными about.json из локального снимка FreeSewing 4.10.2, использованного
при предыдущем исследовании. Поле verified_on относится к странице модели.
Для обновления импорта требуется путь --metadata-root к designs/ официального
репозитория https://codeberg.org/freesewing/freesewing.

## Изображения и лицензия

Изображения не генерируются и не копируются в приложение. Они загружаются
с официального cdn.freesewing.eu, с указанием источника и ссылками на работы.
При недоступности CDN показывается сообщение, без замены на выдуманную модель.
Сложность указана по пятибалльной шкале источника.

Код конструкций FreeSewing лицензирован MIT; копия уведомления сохранена в
licenses/freesewing-MIT.txt. MIT не заявляется как лицензия фотографий:
права на фотографии сохраняются у авторов. Это отмечено на странице модели.

## Проверки

Тесты проверяют контракт API, синхронность снимков, отсутствие подмены моделей
параметрическими пресетами, соответствие design ID в исходном URL редактора,
ссылки на примеры и уникальность моделей. Браузерные сценарии проверяют поиск,
разделы, отсутствие результатов, страницу Simon, реальные изображения,
ссылки на оригиналы, мобильную компоновку, английский язык и 404.

Результат: 195 Python-тестов и 29 браузерных сценариев общего прогона прошли.
После уплотнения мобильного фильтра повторно прошли сценарии библиотеки и
старого конструктора. Svelte: 0 ошибок/предупреждений, RU/EN: 291 ключ,
production build успешен, Impeccable detect без замечаний.


## Расширение: три источника, 85 моделей

Добавлены 6 проверенных статей Mood Sewciety и 6 Tiana’s Closet. Всего 85 моделей:
73 FreeSewing + 6 Mood + 6 Tiana. Ссылки взяты с официальных страниц:
- https://blog.moodfabrics.com/category/free-sewing-patterns/
- https://tianascloset.com/

Mood требует имя и email на своём сайте, затем отправляет ссылку на PDF.
Приложение не отправляет эти данные. У Tiana статьи содержат ссылки на страницы
получения выкроек в собственном магазине. Условия использования смотрят у автора;
лицензия MIT не приписывается этим издателям. Превью издателя не обозначается как
доказательство реально сшитой вещи. Классификация новых статей — редакционная,
по названиям. Сложность не выдумывается: при отсутствии числовой оценки она скрыта.

Peppermint (502) и Fabrics Store (403) не включены без проверки страниц.
Импорт: scripts/import_extra_sources.py, исходные HTML в work/library-sources.
Повторное обновление: сначала импорт FreeSewing, затем импорт дополнительных
источников. Это проверенный снимок каталога, а не автоматический скрейпинг при
каждом открытии приложения.

Поиск поддерживает независимые от порядка слова, регистр, ё/е, отдельные
русские синонимы/транслитерации, окончания и опечатку в длинном слове
(включая перестановку соседних букв). Фильтры раздела и источника применяются
совместно; сброс очищает все фильтры. Исходные имена и авторство сохранены.

Изображения: ленивые карточки, асинхронное декодирование, фиксированная область
для предотвращения сдвигов. Главная фотография модели загружается приоритетно.
Для 12 новых моделей используются реальные srcset издателя и sizes для карточек
96/120 px и главного изображения 360 px. Проверены 71 URL оригиналов/вариантов,
все HTTP 200; отчёт work/extra-source-images.json. FreeSewing продолжает отдавать
свои исходные WebP: дополнительные размеры для его CDN не выдумываются.

Главное изображение отображается без обрезки одежды и открывается в исходном
размере по нажатию. Переход к другой странице сбрасывает внутреннюю прокрутку,
чтобы длинный каталог не открывал карточку модели с середины страницы.

Итоговая проверка: 195 Python-тестов, 36 браузерных сценариев прошли.
Svelte: 0 ошибок и предупреждений; 323 ключа RU/EN; production build успешен.
Impeccable detect не выдал замечаний. Изображения и компоновка проверены визуально.
