# Рабочий экран модельера

Обновление 2026-11-04. Режим интерфейса: Operate. Сохранены компоненты,
палитры и типографика существующего @monos/ui.

## Изменения

- Боковые панели скрываются независимо. «Развернуть лекала» скрывает обе;
  повторное нажатие возвращает панели.
- На узком экране чертёж идёт первым; настройки и печать доступны ниже.
- Мерки разделены на обхваты, плечо/рукав и длины/высоты. Группы сворачиваются.
- Профили клиентов сохраняются локально в браузере. Совпадающее имя обновляет
  профиль, включая мерки, ранее сохранённые для других моделей. При применении
  используются только допустимые мерки текущей модели. Недостающие поля не
  обнуляются, пользователь получает сообщение о частичном применении.
- Сравнение двух именованных швов показывает длины и абсолютную разницу в см;
  выбранные контуры подсвечиваются. Длина считается по всем сегментам кривой.
  Автоматического вывода «посадка верна» нет: разница может быть припосадкой.
- Линейка измеряет прямое расстояние между двумя точками в координатах лекала.
  Она не измеряет длину кривой и не зависит от масштаба экрана. Третья точка
  начинает новое измерение; Escape завершает режим.
- Перетаскивание поля переведено из экранных пикселей в координаты SVG:
  чувствительность перемещения теперь учитывает масштаб и размер окна.
- Легенда объясняет базовый контур/шов, срез с припуском, долевую, сгиб,
  внутренние линии и надсечки. Сгиб отображается отдельным типом штриха.
- Язык, тема и каталог иконок собраны в раскрываемые «Настройки».

## Проверки

Svelte check, совпадение RU/EN словарей, production build. Impeccable detect
для изменённых компонентов не выдал замечаний. Выполнена визуальная проверка
рендеров на десктопе и в узком viewport; это не проверка физического телефона.
Браузерные тесты включают сохранение/восстановление/удаление профиля, раскрытие
панелей, точность линейки через SVG-преобразование, сравнение швов по ответу API,
печать, ошибки, смену языка и прежние сценарии 3D.

Профили не синхронизируются между устройствами и пропадут при очистке данных
сайта. Расчёт швов использует дискретные точки, возвращаемые построителем.
Проверка интерфейса не заменяет проверку посадки на макете.

Результат: 14 общих браузерных сценариев и 5 сценариев рабочего экрана прошли.
Svelte: 0 ошибок, 0 предупреждений; RU/EN: 241 ключ.


## Плотность и адаптивная компоновка

Единая шкала отступов: 4 / 8 / 12 / 16 / 24 px. Между рабочими зонами - 8 px,
между полями - 12 px. Боковые панели на большом экране: 240 и 260 px.
Дублирующий бренд в панели инструментов скрыт; слои перенесены в раскрываемое
меню. Высота приложения привязана к динамической высоте viewport (100dvh).

ПК и ноутбук шире 1180 px: мерки, поле лекал и проверка/печать стоят рядом.
На планшете до 1180 px поле изначально занимает всю ширину, боковые панели
открываются по одной. Ниже 768 px панели открываются поверх поля с отдельной
прокруткой, сохраняя высоту чертежа. При переходе через breakpoint применяется
соответствующая компоновка. Открытые панели закрываются теми же кнопками.

Проверяемые размеры: 1440×900, 1366×768, 1024×768, 834×1194, 390×844.
Измеряется доступная высота/ширина чертежа, отсутствие горизонтального
переполнения и работа панелей. Отдельно проверяется изменение ширины окна.

Проверка адаптива: 24 сценария общего прогона прошли; после последней правки
отступов и ресайза повторно прошли 11 сценариев печати и адаптива, включая
новый тест изменения ширины окна. Impeccable detect: без замечаний.
