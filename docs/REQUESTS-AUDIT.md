## Замечания ревью, оставленные на потом

- Хранилище проектов - один массив в localStorage: две вкладки могут
  перезаписать друг друга. Нужен отдельный ключ на проект.
- Вложения проекта стоит хранить в IndexedDB: квота localStorage 5-10 МБ.
- Нет восстановления из общей резервной копии (экспорт есть).
