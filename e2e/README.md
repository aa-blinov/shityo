# Проверка в браузере

Здесь два разных инструмента: тесты (assert-ы, падают при ошибке) и
обход (снимает скрины, чтобы глазами увидеть результат).

## `npx playwright test` - тесты

Сценарий пользователя: открыть каталог, выбрать модель, изменить мерку,
убедиться, что лекало перестроилось, проверить ответ API. Поднимает
бэкенд и фронтенд сам, если они не запущены.

## `npx tsx ui-tour.ts` - обход со скринами

Протыкивает всё подряд и снимает 19 скринов в `work/shots/ui/`:

| Скрин | Что проверяет |
|---|---|
| `01-catalog` | каталог: карточки моделей, счётчики, подписи |
| `02-tee` | рабочая область: чертёж, детали, мерки, параметры |
| `03-measurement-changed` | смена обхвата груди перестраивает лекало |
| `04-fit-loose` | смена посадки на свободную |
| `05-neckline-v` | смена горловины на V-образную |
| `06-no-allowance` | выключен слой припуска |
| `07-no-grain` | выключен слой долевой нити |
| `08-piece-selected` | выбор детали в списке |
| `09-zoom-in` | приближение холста |
| `10-zoom-fit` | вписывание в окно |
| `11-size-42` | применение размера 42 из сетки |
| `12-3d` | 3D-превью с манекеном |
| `13-shirt`, `13-trousers`, `13-skirt` | остальные модели |
| `14-mobile` | узкий экран (420 px) |
| `15-english` | английский интерфейс |
| `16-light` | светлая тема |
| `17-catppuccin` | другая палитра киты |

Обход проверяет и локализацию: русский по умолчанию, переключение на
английский, сохранение языка при перезагрузке, перевод замечаний
валидатора и работу тем.

Обход падает с ненулевым кодом, если что-то сломалось, и печатает список
проблем в конце.

### Что нужно для прогона

```bash
# бэкенд
.venv/Scripts/python.exe -m uvicorn app.main:app --app-dir backend --port 8000

# фронтенд (production-сборка!)
cd frontend && npm run build && npm start
```

Важно: обход бьёт по **собранному** фронтенду, поэтому после правок в
`frontend/src` нужно пересобрать (`npm run build`) и перезапустить сервер.

### Отдельные отладочные скрипты

- `measure-canvas.ts` - печатает размеры холста, viewBox и экранные
  координаты деталей. Нужен, когда леталы «обрезаются по краю окна».
- `screenshot-3d.ts` - снимает только 3D-превью.
- `screenshots.ts` - снимает четыре модели в `work/shots/`.
